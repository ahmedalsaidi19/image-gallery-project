# معرض مشاركة الصور

## الوصف
هذا معرض مشروع تخرج كان مطلوب مني في أكاديمية حاسوب، يتيح للمستخدمين تصفح الصور، رفع الصور الخاصة بهم، تعديلها، وحذفها، بالإضافة إلى نظام إعجابات تفاعلي.

---

## إعداد ملف البيئة (.env)
قبل تشغيل المشروع، قم بإنشاء ملف `.env` داخل مجلد الخادم (Server) وضع فيه المتغيرات التالية:
```env
PORT=5000
MONGO_URI=ضع رابط اتصال قاعدة البيانات هنا
JWT_SECRET=ضع الرمز السري الخاص بك هنا

```

---

## طريقة تشغيل المشروع

لتشغيل المشروع على أي جهاز، يرجى اتباع الخطوات التالية:

### 1. تشغيل طرف الخادم (Server)

قم بفتح الطرفية (Terminal) وانتقل إلى مجلد السيرفر، ثم قم بتثبيت المكتبات وتشغيل الخادم بالأوامر التالية:

```bash
cd server
npm install
npm start

```

### 2. تشغيل طرف العميل (Client)

قم بفتح نافذة طرفية جديدة، وانتقل إلى مجلد العميل، ثم قم بتثبيت المكتبات وتشغيل الواجهة بالأوامر التالية:

```bash
cd client
npm install
npm start

```

بعد تنفيذ هذه الخطوات، سيتم تشغيل المشروع بنجاح في المتصفح! 🚀
